# DHCP

VB.NET DHCP sample that queries a DHCP.Server and message-boxes version, subnets, and client lease/reservation details. modMain walks each subnet's ClientEntry list (IP, name, mask, MAC, comment, lease vs reservation). Form1 is an empty WinForms shell and is the recorded startup form; DHCP.Server is used in code but is not compiled in this project, so the tree is an incomplete working copy.
